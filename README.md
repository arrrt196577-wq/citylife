# CityLife 仓库索引

供 AI 按任务定位相关目录和文件。

## 仓库根目录

| 路径 | 用途 |
| --- | --- |
| [README.md](README.md) | 仓库的目录和文件索引。 |
| [ArtSource/](ArtSource/) | 像素画原稿、参考图和 AI 素材生成记录。 |
| [Game/](Game/) | Unity 项目所在目录。 |

## Unity 游戏内容

| 路径 | 用途 |
| --- | --- |
| [Game/Assets/CityLife/](Game/Assets/CityLife/) | CityLife 的游戏代码和素材。 |
| [Scenes/](Game/Assets/CityLife/Scenes/) | Unity 场景，包括场景中的地图布局。 |
| [Scripts/](Game/Assets/CityLife/Scripts/) | C# 游戏逻辑。 |
| [Prefabs/](Game/Assets/CityLife/Prefabs/) | 可在场景中复用的角色和道具预制体。 |
| [Art/Characters/](Game/Assets/CityLife/Art/Characters/) | 角色精灵和动画图集。 |
| [Art/Tilesets/](Game/Assets/CityLife/Art/Tilesets/) | 地面、道路和墙壁等地图图块。 |
| [Art/Props/](Game/Assets/CityLife/Art/Props/) | 招牌、售货机和家具等道具素材。 |
| [Animations/](Game/Assets/CityLife/Animations/) | Unity 动画片段和 Animator Controller。 |
| [Audio/](Game/Assets/CityLife/Audio/) | 游戏音效和音乐。 |

Unity 项目初始化时会生成依赖目录 Packages 和项目设置目录 ProjectSettings。
