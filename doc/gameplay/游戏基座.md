# 游戏基座

## 项目定位

CityLife 是一款以城市日常生活为背景的像素风模拟经营游戏。玩家从 2D 俯视视角操控主角。

## 当前原型

- 主角可以在场景中行走，停止时保持朝向并切换到待机动画。
- 主角可以步行进出咖啡厅。进入室内时隐藏建筑外观，离开后恢复显示。
- 墙体与家具设有碰撞，主角与家具按接地点排序。

可在 Unity 的示例场景中查看上述行为。[SampleScene.unity](../../Game/Assets/Scenes/SampleScene.unity)

## 基础系统（暂定）

- 时间系统
- 经济系统
- 健康系统
- 社交系统

## 待定义的基础玩法

- **经营目标**涉及主角经营什么，以及经营如何带来成长。
- **核心循环**涉及玩家反复做什么、获得什么反馈，以及如何开始下一轮。
- **城市日常**涉及主角在城市中的身份，以及日常活动如何影响经营。
